# Product

## Register

product

## Platform

web

## Users

The primary user is an individual job seeker running the application locally. They want to configure their own compatible LLM and embedding services, provide a JD and master resume with optional supporting materials, understand what the Agent is doing, and review the result without using a CLI.

## Product Purpose

Provide one focused workspace for configuring a resume Agent, submitting source material, observing the LangGraph workflow, and reviewing evidence-grounded output. Success means a user can complete the entire workflow from one page and diagnose slow or failed model calls without inspecting terminal logs.

## Positioning

A transparent resume workflow that shows how every model step and evidence decision produces the final result.

## Brand Personality

Precise, calm, and transparent. The interface should feel like a professional workbench while offering AI-laboratory depth through optional execution details.

## Anti-references

Do not resemble a chatbot, a marketing site, or a collection of decorative cards. Avoid glowing gradients, generic purple AI styling, excessive raw logs, novelty controls, and visual effects that compete with the task.

## Design Principles

- Keep the shortest path from inputs to a reviewed resume obvious.
- Show current progress first; reveal technical depth on demand.
- Make model configuration explicit and testable before a full run.
- Treat failures as diagnosable workflow states, not generic error banners.
- Preserve evidence traceability from uploaded sources to final output.

## Accessibility & Inclusion

Target WCAG AA. Support full keyboard operation, visible focus, reduced motion, state communication beyond color, field-associated errors, and screen-reader-readable workflow progress.
