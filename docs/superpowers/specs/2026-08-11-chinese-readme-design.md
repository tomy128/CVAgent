# 中文 README 设计

## 用户目标

让第一次接触 CV Agent 的中文用户快速理解产品价值、事实安全边界、主要产物，并能在本地成功启动。README 同时为开发者保留必要的技术原理和验证入口。

## 核心取舍

采用产品优先的信息顺序，而不是逐句翻译旧 README。先回答“它解决什么问题、界面是什么样、能产出什么”，再介绍安装、隐私与技术架构，从而缩短首次理解和启动路径。技术说明保持准确，但不展开内部实现细节。

## 内容结构

1. 使用 `CV Agent` 作为页面主标题，用一句话解释它是本地运行、证据驱动的求职简历 Agent。
2. 在简介后通过相对路径 `./screen-shot.png` 展示当前工作台截图，并提供中文替代文本。
3. 核心能力涵盖：岗位要求解析、履历证据匹配、可投递简历生成、能力差距与提升路线、目标简历、面试准备、人工审核与可追踪执行。
4. 解释各类 Markdown/JSON 输出，以及简历产物跟随主简历语言、分析产物跟随 JD 语言的规则。明确 `target-resume.md` 只在存在重要能力差距时生成，属于不可审核、不可投递的目标版本；只有 `application-resume.md` 可以进入人工审核并用于投递。
5. 保留 Python 3.13、`uv`、安装、启动、访问地址、模型配置和 Demo 模式说明。
6. 说明 API Key 保存在浏览器本地存储，输入、checkpoint、事件与产物位于本地 `output/<run-id>/`，元数据会脱敏。
7. 用精炼中文介绍 LangChain、LangGraph、确定性 Markdown 渲染、上下文拆批、恢复机制和禁止编造事实的安全边界。
8. 保留 `uv run pytest` 验证命令。

## 范围与风险

只修改 README、新增并跟踪用户提供的截图，以及维护任务文档；不修改源代码、示例输入或依赖。风险主要是产品名与包名不同：用户界面称为 `CV Agent`，命令和项目内部标识继续使用现有 `resume-agent-web` 与 `nonote-resume`，避免破坏运行方式。
